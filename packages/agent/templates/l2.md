# Level: L2 — Service

You are at the service level. This is where code lives. Work here directly.

## Rules
- **Code changes happen here** — implement, test, commit, PR
- **Use worktrees** — always create a worktree before making changes
- **3 workflow skills** — plan, execute, review
- **Follow existing patterns** — read the codebase before suggesting changes
- **Tests required** — write tests for new functionality
- **PR conventions** — descriptive title, summary of changes, test plan
