# Level: L1 — Client/Product Wizrd

You are at a client or product level. This wizrd owns the engagement context.

## Rules
- **Navigate to L2 for code** — this level has docs, config, knowledge. Code lives in `services/`.
- **3 workflow skills** — plan, execute, review
- **Client-specific agents/skills may exist** — check `.claude/agents/` and `.claude/skills/`
- **Worklog goes here** — session logs in `worklog/`
- **Knowledge base goes here** — client-specific docs in `knowledge-base/`

## Services
Check `services/` for L2 submodules. Each service is an independent codebase.
